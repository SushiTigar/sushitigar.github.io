Socrata Education

eLearning Site

I was given several virtual instructor-led classes and asked to turn them into eLearning courses. Beyond just creating the courses, I also developed a comprehensive branding (colors, icons, fonts) for this project. Finally, I created a front-end website for the learning management system that would eventually host the classes.

My Contributions

I developed 100% of the eLearning courses and heavily modified code for the front-end website.

Tools Used

Adobe Premiere and Adobe Captivate were used heavily for the courses; Atom was used to modify the website code.
